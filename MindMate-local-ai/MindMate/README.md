# MindMate — بالذكاء الاصطناعي المحلي

MindMate صار يشتغل على **موديل محلي على جهازك** (Gemma 4 12B) بدل OpenAI: ما يحتاج API key، ولا اشتراك، ولا يطلع كلام الطلاب من جهازك.

```
المتصفح (templates + static)
      │  POST /chat  ← الرسالة + الشعور + المحادثة السابقة
      ▼
Flask (app.py)
      ├─ 🛡️ safety.py: خطر واضح → رد ثابت + أرقام المساعدة (الموديل ما يرد)
      ├─ 🧠 engine.py: الموديل على الـ GPU، والرد يطلع كلمة كلمة
      └─ 🛡️ OutputGuard: لو قال شي ممنوع → يكتب رد جديد
```

## التشغيل (Windows PowerShell)

إذا سند مثبّت على نفس الجهاز، `run.ps1` يستخدم نفس البيئة والموديل، وما ينزّل شي كبير:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 -Mock   # تجربة الواجهة بدون موديل
powershell -ExecutionPolicy Bypass -File .\run.ps1         # الموديل الحقيقي
```

افتح: **http://127.0.0.1:5000**

جهاز جديد بدون سند؟ شغّل `setup.ps1` أول مرة.

**الاختبارات:** `python -m pytest -q`

## الملفات

| الملف | وش فيه |
|---|---|
| `app.py` | السيرفر (Flask) — نفس المسار `/chat` اللي كان |
| `prompts.py` | شخصية MindMate وأمثلة أسلوبه — عدّل هنا عشان تحسّن الردود |
| `safety.py` | طبقة الأمان: كشف الخطر بالعربي والإنجليزي + فحص الرد |
| `engine.py` | المحرك المحلي (نفس محرك سند) |
| `config.py` | الموديل، البورت، أرقام المساعدة |

## قبل ما تنشره للطلاب

- صور `static/characters/` شخصيات محمية بحقوق نشر — بدّلها برسومات أصلية قبل أي نشر عام.
- مختص نفسي يراجع الشخصية والردود الثابتة.
- راجع أرقام المساعدة في `config.py`.
- لا تفتح البورت للإنترنت مباشرة؛ استخدم Tunnel أو HTTPS، وضيف تسجيل دخول و rate limit.
